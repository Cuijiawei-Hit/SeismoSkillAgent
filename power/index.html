Use the platform locally.

Install once, explore the included case, then connect your own model account. New calculations retain plan validation, human approval, result review and expert feedback.

Download and install

Install Python 3.13. Download the complete Release ZIP and extract it. In the extracted PowerSkillAgent directory, run:

powershell -ExecutionPolicy Bypass -File .\install-power.ps1

Choose the named platform ZIP, rather than GitHub's automatic “Source code” archive, to include the case data and knowledge files.

Open the default case

.\start-power.cmd

Visit http://127.0.0.1:8785. The Auckland result opens automatically. Viewing the saved example needs no API key.

Connect your own model

.\configure-model.cmd

The hidden prompt asks for your own API key. The other settings can be changed to match an OpenAI-compatible provider.

SettingDeepSeek example
API base URLhttps://api.deepseek.com/v1
Modeldeepseek-v4-pro
API keyYour own provider-issued key, entered locally

The script passes the key to the local server process and restarts that server. It does not save the key in a source file or upload it to this website. No shared API key is included in the download.

Create and review a task

Choose New task, describe your question, review the proposed inputs and approve the engineering plan. Inspect the results, accept them or submit a revision. The included case remains available separately.

Windows quick start: 安装依赖后运行 start-power.cmd 查看案例；运行 configure-model.cmd 填写自己的 API 参数，再新建任务。右上角可切换中文。

The knowledge base is included.

The full download carries the curated source texts, hybrid retrieval indexes and a pinned multilingual encoder. Retrieval runs locally on CPU; there is no first-run encoder download.

Knowledge assets occupy about 337 MiB before compression. They are in the Release download, separate from the website, so they do not slow this page. The model and tokenizer account for most of that size.

Original references and document notices remain with the corpus. File hashes are recorded in the knowledge release lock.
