# SeismoSkillAgent

Engineering Skill-augmented human–AI decision support for seismic resilience of urban engineering systems.

**PowerSkillAgent is available:** an independent electricity-grid assessment platform with the saved Auckland case, 87-document knowledge base and local retrieval encoder.

- [Explore the platform and usage guide](https://cuijiawei-hit.github.io/SeismoSkillAgent/power/)
- [Open the interactive Auckland example](https://cuijiawei-hit.github.io/SeismoSkillAgent/power/demo/)
- [Download the complete local platform](https://github.com/Cuijiawei-Hit/SeismoSkillAgent/releases/tag/power-v0.3.1)
- [Application source](platform/)

The complete Release ZIP includes case inputs, saved results, knowledge texts, indexes and encoder weights. It opens the saved case without an API key. New agent tasks use the model API configured by the downloader; no shared DeepSeek key is distributed. See [installation and configuration](platform/README.md).
